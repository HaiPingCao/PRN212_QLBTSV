# Quản lý bài tập sinh viên (QLBTSV)

Quản lý bài tập sinh viên (QLBTSV) là dự án (20%) môn học PRN212

## Mục tiêu dự án

- Tạo ra 1 phần mềm đơn giản để sinh viên, giáo viên, nhà trường để giao, nộp và chấm điểm bài tập cho sinh viên.
- Giúp người làm nắm rõ về EntityFramework, WPF, và .Net

## Cấu trúc dự án

```txt
- /
  - db/ <- Database - SQL file
  - docs/ <- Các tài liệu liên quan
  - Prototype/ <- Các project để thử nghiệm các chức năng của dự án
  - QLBTSV_re/ <- Dự án chính
    - QLBTSV_re.Shared
    - QLBTSV_re.Client
    - QLBTSV_re.Server
```

## Biên dịch dự án

### Yêu cầu dự án

- DotNet SDK 8
- Visual studio 2022 hoặc cao hơn, cùng với ".NET desktop development"

### Chạy dự án

- Chạy multi-startup (`Run all`), đã được cấu hình sẵn trong Visual Studio.
