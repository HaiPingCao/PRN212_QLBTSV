# Quản lý bài tập sinh viên (QLBTSV)

## Cấu trúc dự án

```txt
- /
  - db/ <- Database - SQL file
  - docs/ <- Các tài liệu liên quan
  - Prototype/ <- Các project để thử nghiệm các chức năng của dự án
  - QLBTSV_re/ <- Dự án chính
    - QLBTSV_re.Shared
    - QLBTSV_re.Client
    - QLBTSV_re.Server
```

## Biên dịch dự án

### Yêu cầu dự án

- DotNet SDK 8
- Visual studio 2022+

### Chạy dự án

- Chạy multi-startup (`Run all`), đã được cấu hình sẵn trong Visual Studio.
