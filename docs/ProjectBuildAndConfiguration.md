# Cấu hình và biên dịch dự án

## 1. Cấu hình Visual Studio

- Yêu cầu: Đã cài đặt VS22
- Trong Visual Studio Installer, chọn More > Import configuration > [Chọn file .vsconfig](../.vsconfig) và cài đặt các tools.

## 2. Biên dịch chạy dự án

- Chạy multi-startup (`Run all`), đã được cấu hình sẵn trong Visual Studio.
